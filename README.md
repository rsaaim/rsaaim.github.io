# rsaaim.github.io

Portfolio site for Rayhaan Saaim. Plain HTML/CSS/JS, hosted on GitHub Pages.

- Page content lives in `tools/build.py`. Edit it, then run `python3 tools/build.py` to regenerate `index.html` and `projects/*.html`.
- Styles: `css/style.css` (light theme by default, dark theme under `[data-theme="dark"]`).
- Photos: `assets/img/<project>/`.
- Resume: `resume.pdf`.
